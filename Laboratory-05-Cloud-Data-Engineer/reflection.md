During this laboratory activity, I learned more about cloud storage and how it is used to store and manage files. I realized that object storage is a good choice for applications that need to store millions of photos because it can handle large amounts of data and grow as the number of users increases. Unlike a traditional hard drive that uses block storage, object storage keeps files as individual objects with their own information and identifiers. This makes it useful for applications such as photo-sharing platforms.

I also learned how Docker makes it easier to deploy MinIO. Instead of installing and configuring everything manually, I could use a Docker command to run the storage server in a container. I learned that environment variables can be used to set the login credentials and that port mapping allows users to access the web console through a browser. Although I encountered some problems with downloading the MinIO image, the experience helped me understand that troubleshooting is an important part of working with cloud technologies.

Another thing I learned is the meaning of a bucket in object storage. A bucket is like a container where files are stored and organized. For example, the `client-photos` bucket can hold the images uploaded by users of a photo-sharing application.

I also realized that large companies need to protect their data from hardware failures. They can do this by keeping copies of their files on different servers, using replication, and maintaining backups in separate locations. These methods help prevent data loss when a physical server stops working.

Overall, this activity helped me become more familiar with the Linux command line and Docker. I am still learning, but I feel more confident about running commands, checking containers, and understanding how cloud storage works. This experience taught me that patience and problem-solving are important skills in cloud computing, and I look forward to improving these skills in future activities.
