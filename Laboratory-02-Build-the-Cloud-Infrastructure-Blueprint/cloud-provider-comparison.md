## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers a very broad range of cloud services and has a large global cloud ecosystem. Chapter 2 identifies AWS as the largest and most widely adopted cloud computing platform.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

Microsoft Azure would be a suitable choice for an organization that primarily uses Microsoft products. Azure is designed to integrate closely with technologies such as Windows Server, Active Directory, Microsoft 365, and SQL Server.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

Google Cloud Platform is widely recognized for artificial intelligence, machine learning, large-scale data processing, and cloud-native technologies. Chapter 2 also explains that Kubernetes originated from Google's internal infrastructure.

### 4. What similarities did you observe among the three cloud providers?

AWS, Microsoft Azure, and Google Cloud all provide similar core infrastructure services, including computing, storage, networking, and identity management. They all allow organizations to use cloud resources without having to maintain all of the underlying physical infrastructure themselves.
