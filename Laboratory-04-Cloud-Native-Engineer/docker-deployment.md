## Container Lifecycle

| Command | What It Does |
|---|---|
| `docker ps` | This command displays the Docker containers that are currently running. |
| `docker stop nginx-server` | This command stops the running Nginx container without removing it. |
| `docker ps -a` | This command displays all containers and allows me to verify that the Nginx container has stopped. |
| `docker rm nginx-server` | This command removes the stopped Nginx container completely from the Docker environment. |
