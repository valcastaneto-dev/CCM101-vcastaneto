# 🪞 Mission Reflection

</div>

---

After completing this mission, I learned a lot more about cloud computing and how AWS, Microsoft Azure, and Google Cloud Platform are used in real-world situations. Among the three, AWS impressed me the most because it offers a very wide range of services and can support both small and large businesses. I also liked how flexible AWS is and how it can handle different types of workloads.

One thing I noticed is that AWS, Azure, and GCP have many similarities. All three provide services for virtual machines, storage, databases, networking, security, identity management, and Kubernetes. They also allow businesses to increase or decrease their resources depending on their needs, which makes cloud computing more flexible than using only physical servers.

I also realized that business requirements are very important when choosing a cloud platform. For example, a university that already uses Microsoft products would probably benefit more from Azure because of its strong integration with Microsoft technologies. On the other hand, a company focused on AI and machine learning might choose Google Cloud because of its strong AI and data services.

Being a Cloud Solutions Consultant helped me understand that there is no single cloud platform that is perfect for every business. I learned that I need to look at the client's budget, existing technology, goals, performance needs, and future growth before making a recommendation. This helped me improve my problem-solving and decision-making skills.

Lastly, my GitHub Cloud Computing Portfolio has improved because I now have organized documentation showing what I learned. The different checkpoints gave me practical experience in comparing cloud platforms, matching services, making recommendations, and investigating Linux systems. Overall, this mission gave me a better understanding of cloud computing and made me more confident about using cloud technologies in future projects.
