## 🧭 Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, databases, networking, security, AI, analytics, application development, and hybrid-cloud environments.

Azure is particularly useful for organizations that already use Microsoft technologies such as **Windows Server**, **Microsoft SQL Server**, **Microsoft 365**, **Active Directory / Entra ID**, and other Microsoft enterprise products.

---

## 🌍 Global Infrastructure

Azure has one of the world's largest cloud infrastructures.

> Microsoft's current global infrastructure page lists **80+ Azure regions** and **500+ datacenters**.
> *(Source: azure.microsoft.com/explore/global-infrastructure — verify current figures before submission, as these numbers change as Azure expands.)*

Azure regions are organized into **geographies**, which help organizations address latency, data residency, and compliance requirements. Azure also uses **Availability Zones** — physically separated locations within an Azure region — to improve application availability and resilience.

## 🖥️ Cloud Management Console

The **Azure portal** is Azure's web-based management console. It provides a graphical interface for creating, configuring, monitoring, and managing Azure resources.

**Key features:**
- Central dashboard
- Global search
- Resource menus
- Cloud Shell (in-browser CLI)
- Notifications and alerts
- Settings and support tools
- Resource-management functions

## ⚙️ Four Core Services

| Service | Description |
|---|---|
| **Azure Virtual Machines** | Provides virtualized computing resources for Windows and Linux workloads. |
| **Azure Blob Storage** | Provides scalable object storage for unstructured data such as documents, images, video, and backups. |
| **Azure SQL Database** | Provides a managed relational database service based on Microsoft SQL technologies. |
| **Azure Functions** | Provides serverless, event-driven application execution without requiring users to manage servers. |

Azure VMs provide flexible virtual computing, while Blob Storage is designed for massive amounts of unstructured data. Azure Functions provides serverless execution and event-driven integration.
