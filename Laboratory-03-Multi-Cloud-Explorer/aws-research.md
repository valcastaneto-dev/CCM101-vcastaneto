## 🧭 Brief Overview

Amazon Web Services (AWS) is Amazon's cloud computing platform. It provides a large collection of on-demand services for computing, storage, databases, networking, security, analytics, artificial intelligence, and application development.

AWS allows organizations to obtain computing resources without purchasing and maintaining their own physical data-center infrastructure. Its services are available through the **AWS Management Console**, command-line tools, APIs, and SDKs. AWS currently provides **more than 200 services** through its cloud platform.

---

## 🌍 Global Infrastructure

AWS organizes its infrastructure into **Regions** and **Availability Zones (AZs)**. A Region is a geographic area containing multiple isolated Availability Zones.

> AWS states that its infrastructure spans **39 geographic Regions** and **124 Availability Zones**, with additional infrastructure announced for the future.
> *(Source: [aws.amazon.com/about-aws/global-infrastructure](https://aws.amazon.com/about-aws/global-infrastructure) — verify current figures before submission, as these numbers change as AWS expands.)*

Each AWS Region has at least **three Availability Zones**, which are physically separated and connected through high-speed, redundant networking. This architecture helps organizations design applications for high availability and fault tolerance.

## 🖥️ Cloud Management Console

The AWS Management Console is a browser-based interface used to access and manage AWS services. Administrators can create resources, configure services, monitor workloads, manage users, and review costs.

**Key features:**
- Unified search and navigation
- Customizable dashboards
- Billing and cost management
- IAM access management
- Monitoring capabilities

## ⚙️ Four Core Services

| Service | Description |
|---|---|
| **Amazon EC2** | Provides resizable virtual servers for running applications and workloads. |
| **Amazon S3** | Provides scalable object storage for files, backups, media, and other data. |
| **Amazon RDS** | Provides managed relational database services. |
| **AWS Lambda** | Runs application code without requiring the organization to manage servers. |

These services represent major AWS capabilities in compute, storage, databases, and serverless computing.

## ✅ Three Advantages

| # | Advantage | Why It Matters |
|---|---|---|
| 1 | **Large service portfolio** | AWS offers a very broad selection of cloud services covering infrastructure, databases, analytics, AI, security, and application development. |
| 2 | **Global infrastructure** | Its large network of Regions and Availability Zones supports worldwide deployment, high availability, and disaster recovery. |
| 3 | **Flexible management** | Organizations can manage resources through the web console, APIs, SDKs, and command-line tools. |
